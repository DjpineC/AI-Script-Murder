# 剧本杀剧本生成提示词 v2.0

## 任务说明
请根据以下模板和约束条件，生成一个完整的剧本杀剧本，输出格式为 JSON，放在代码块中。

## 输出格式模板
{
  "title": "剧本标题",
  "brief": "剧本简介，介绍案件背景，不要泄露凶手。",
  "rounds": 2,
  "narration": "开场旁白，介绍场景和案件。",
  "roles": [
    {
      "name": "角色A",
      "identity": "公开身份",
      "goal": "个人目标，要隐藏或达成的目的",
      "secret": "只有该角色知道的隐藏故事 + 完整个人行动时间线 + 作案过程（凶手必填，非凶手填自己的行动和秘密）",
      "prompt": "性格和说话风格提示"
    }
  ],
  "evidence": [
    [
      "第1轮证据1",
      "第1轮证据2",
      "第1轮证据3",
      "第1轮证据4"
    ],
    [
      "第2轮证据1",
      "第2轮证据2",
      "第2轮证据3",
      "第2轮证据4"
    ]
  ],
  "truth": "完整真相，包括凶手、动机、手法、时间线。",
  "storyEnd": "结局故事，画面感强。",
  "murderer": "角色B"
}

## 核心约束（必须遵守）

### 1. 角色字段要求
每个角色必须包含以下五个字段，缺一不可：
- name：角色名
- identity：公开身份
- goal：个人目标（要隐藏或达成的事）
- **secret：必须同时包含三部分内容**
  1. 该角色完整的隐藏故事和动机
  2. **完整的个人行动时间线**（具体到几点几分做了什么、遇到了谁、看见了什么）
  3. **凶手必须在secret中明确写出自己的作案过程**（几点几分、在哪里、用什么手法、杀死了谁）
- prompt：性格和说话风格提示

### 2. 凶手须知（最高优先级）
- **凶手必须知道自己是凶手**
- 凶手的secret字段中必须包含完整的作案过程，包括：
  - 作案时间（精确到分钟）
  - 作案地点
  - 作案手法
  - 作案前后的行动路线
  - 如何清理痕迹或伪造现场
- 凶手在游戏过程中可以撒谎、可以隐瞒，但必须知道自己的罪行

### 3. 非凶手的要求
- 非凶手的secret中同样需要包含完整的个人行动时间线
- 说明自己每个时间段在哪里、做什么、看到了什么
- 说明自己为什么要隐瞒某些事情（如果有）

### 4. 时间线要求
- 所有角色的行动时间必须一致且可对照
- 时间跨度通常为案发前3-4小时到案发后
- 每个角色的secret中必须有时间线，格式为"HH:MM 做了什么事"

### 5. 证据要求
- 每轮3-5条证据
- 第二轮必须包含指向各个角色的个人证据
- 证据不能直接写出"凶手是XXX"
- 证据要能支撑真相中的推理链

### 6. 真相要求
- 明确写出凶手是谁
- 完整还原作案过程和动机
- 解释所有关键证据的指向
- 说明时间线上的关键矛盾点

## 示例：角色secret字段格式

正确示例（凶手）：
"secret": "你是陈默的合伙人，但被他压了整整一年。你的行动路线：22:00-02:00在工位写代码，01:45和陈默在走廊争吵（内容：'你再提交你的方案我就踢你出去'），02:05看到陈默去接电话，你用他的密码登录电脑执行了git push --force，想让他明天出丑。02:10你听到键盘砸落的声音，回头看到陈默倒在地上，键盘插在他背上。你没有报警，删除了自己的登录日志。你手臂上的划伤是键盘翻转时划到的。你手上的咖啡杯和键盘上的咖啡痕迹吻合。"

正确示例（非凶手）：
"secret": "你有代码洁癖，陈默的代码让你忍无可忍。你的行动路线：23:00-01:30在工位review代码，01:35看到陈默去卫生间，你走到他工位执行了rm -rf .git删了他的本地仓库，01:38回到自己工位。02:00陈默回来尖叫'谁删了我的git'，你说'你自己push --force了吧'。02:50小美尖叫时你正在恢复自己的备份。你始终没有提删仓库的事，但更不敢提的是——你上周给陈默定制键盘时在底壳里焊了一片不锈钢片，本意是'吓唬他'。"

## 错误示例（禁止）

错误写法1（凶手不知道自己是凶手）：
"secret": "你忘了02:10做了什么，只记得听到键盘响了一声。"

错误写法2（没有时间线）：
"secret": "你恨陈默，你偷偷做了些事。"

错误写法3（凶手情节缺失）：
"secret": "你是凶手。你的行动路线：22:00到公司，然后发生了争执……（模糊不清）"
