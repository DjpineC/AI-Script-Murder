# AI 剧本杀 · CMD 引擎

一个用原生 JavaScript 写的本地 AI 剧本杀游戏。

玩家上传 JSON 剧本，AI 扮演剧中角色，玩家在 CMD 风格界面里和角色对话、搜证、投票，最后找出真凶。

体验地址：https://ai-jokerpaly.netlify.app

---

## 这是什么

这不是一个自带剧本的聊天游戏，而是一个“剧本杀引擎”。

你需要准备一个符合格式的 JSON 剧本，引擎会读取剧本，并把里面的角色交给 AI 扮演。

你扮演其中任意一个或多个角色，通过对话、质问、搜证、投票，找出杀害剧本中受害者的真凶。

---

## 特点

- 纯前端运行，不需要后端服务器
- 原生 JS 调用 AI API
- 支持符合 OpenAI 协议的接口，可接入 DeepSeek 等模型
- 玩家自行上传 JSON 剧本
- CMD 风格界面
- 支持 @ 角色、@所有人
- 每 10 轮对话自动更新所有 AI 角色的长期记忆
- 每次发言只发送：
  - 角色人设
  - 公开证据
  - 最近 5 条公开对话
  - 长期记忆
- 显示 token 消耗、缓存命中率、预计花费
- 可查看角色“大脑”，方便判断 AI 状态

---

## 快速开始

1. 打开网页
2. 点击右上角“设置”
3. 填写 Base URL
4. 填写 API Key
5. 点击“获取模型”
6. 选择模型
7. 选择剧本文件夹，加载 JSON 剧本
8. 勾选你想扮演的角色
9. 点击“开始游戏”

## 玩法说明

### 对话

你可以直接输入普通对话。

如果想指定某个人回应，使用：

@周野 你昨晚十点在哪？

如果想所有人依次发言，使用：

@所有人

### 搜证

自我介绍结束后，输入：

/endintro

进入第一轮搜证。

每轮搜证结束后，输入：

/search

进入下一轮。

### 投票

最后一轮搜证结束后，输入：

/vote

进入投票。

## 长期记忆机制

每累计 10 条正常对话，系统会为所有 AI 角色更新一次长期记忆。

长期记忆内容包括但不限于：

- 谁在怀疑我
- 我在怀疑谁
- 我撒过什么谎
- 什么证据对我不利
- 我接下来需要解释什么

更新完成后，公屏会显示：

[系统] 长期记忆更新完成。
记忆消耗 token：xxxx
记忆平均缓存命中率：xx%
记忆消耗预计：¥x.xxxx

## 剧本格式

剧本必须是合法 JSON，扩展名为 .json。

最少需要以下字段：

{
  "title": "剧本标题",
  "brief": "剧本简介",
  "rounds": 2,
  "narration": "开场旁白",
  "roles": [],
  "evidence": [],
  "truth": "完整真相",
  "storyEnd": "结局故事",
  "murderer": "凶手角色名"
}

角色字段：

{
  "name": "角色A",
  "identity": "公开身份",
  "goal": "个人目标",
  "secret": "隐藏故事 + 完整时间线 + 作案过程（凶手必填）",
  "prompt": "性格和说话风格提示"
}

证据字段：

[
  ["第1轮证据1", "第1轮证据2", "第1轮证据3"],
  ["第2轮证据1", "第2轮证据2", "第2轮证据3"]
]

## 已知问题

- AI 偶尔可能返回空内容
- 凶手角色有时会因为提示词压力而自爆
- 缓存命中率受剧本长度和对话复杂度影响
- 不同模型对 JSON 和角色扮演的理解存在差异
- AI 偶发对话截断

## 剧本生成提示词 v2.0

你可以把下面这段提示词发给 AI，让它生成一个完整剧本。

### 任务说明

请根据以下模板和约束条件，生成一个完整的剧本杀剧本。  
输出格式为 JSON，放在代码块中。

### JSON 模板

{
  "title": "剧本标题",
  "brief": "剧本简介，介绍案件背景，不要泄露凶手。",
  "rounds": 2,
  "narration": "开场旁白，介绍场景和案件。",
  "roles": [
    {
      "name": "角色A",
      "identity": "公开身份",
      "goal": "个人目标，要隐藏或达成的目的",
      "secret": "隐藏故事 + 完整时间线 + 作案过程（凶手必填）",
      "prompt": "性格和说话风格提示"
    }
  ],
  "evidence": [
    ["第1轮证据1", "第1轮证据2", "第1轮证据3"],
    ["第2轮证据1", "第2轮证据2", "第2轮证据3"]
  ],
  "truth": "完整真相，包括凶手、动机、手法、时间线。",
  "storyEnd": "结局故事，画面感强。",
  "murderer": "角色B"
}

### 核心约束

- 每个角色必须有 name、identity、goal、secret、prompt 五个字段。
- 每个角色的 secret 必须包含三部分：
  1. 隐藏故事和动机
  2. 完整个人行动时间线，精确到分钟
  3. 凶手必须明确写出作案过程
- 凶手必须知道自己是凶手。
- 非凶手的 secret 也必须包含完整时间线。
- 所有角色时间线必须相互一致，可对照。
- 证据每轮 3 到 5 条。
- 第二轮证据必须包含指向不同角色的个人证据。
- 证据不能直接写出“凶手是XXX”。
- truth 必须完整解释凶手、动机、手法和时间线。
- murderer 必须与某个角色名完全一致。
- 最终输出必须是合法 JSON。
